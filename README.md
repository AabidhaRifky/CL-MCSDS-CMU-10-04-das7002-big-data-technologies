## Notebook order
Run the notebooks in this order:

1. 01_task1_data_engineering.ipynb
2. 02_task2_high_dimensional_eda.ipynb
3. 03_task3_unsupervised_clustering.ipynb
4. 04_task4_supervised_ml.ipynb

Task 1 prepares and saves the cleaned data that is used by the later notebooks.

## Task 1
01_task1_data_engineering.ipynb

This notebook handles the main ETL process.

It includes:
schema enforcement  
data quality checks  
timestamp cleaning  
location validation  
missing-value checks  
duplicate checks  
feature creation  
weather data cleaning  
Parquet conversion  
Year and District partitioning

The processed output is saved under:
data/processed/

## Task 2
02_task2_high_dimensional_eda.ipynb

This notebook contains the exploratory analysis.

It includes:
annual crime analysis  
monthly crime patterns  
daily averages  
weekday and hourly analysis  
community-area analysis  
rolling averages  
broadcast joins  
weather analysis  
socioeconomic analysis

The main figures generated by the analysis are saved under:
outputs/figures/

## Task 3
03_task3_unsupervised_clustering.ipynb

This notebook performs K-Means clustering using latitude, longitude and time-of-day features.
Different values of K were tested using the elbow method and Silhouette score.
The final selected value was:
K = 5
The saved model is stored under:
outputs/models/

## Task 4
04_task4_supervised_ml.ipynb

This notebook develops Random Forest models to predict the likelihood of arrest.
It includes:
feature preparation  
categorical encoding  
missing-value handling  
baseline Random Forest  
class-weighted Random Forest  
confusion matrix  
accuracy  
precision  
recall  
F1-score  
ROC-AUC  
PR-AUC

The generated model files are stored under:
outputs/models/

Download the raw Chicago Crime dataset from Google Drive.
Place and extract it inside data/raw/.
Run Task 1 first.
Then run Task 2, Task 3 and Task 4 in order.
