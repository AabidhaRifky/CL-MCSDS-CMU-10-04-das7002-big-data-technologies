
inside:

\### 5. Set Up the Saved Spark Models



Extract:



```text

models.zip

```



into:



```text

```



The final location should therefore be:



```text

outputs/models/

```



This folder contains the saved Spark ML models generated during Tasks 3 and 4, including the K-Means and Random Forest models.



The `outputs/models/` directory is not committed directly to GitHub because Spark ML model directories contain many generated metadata and Parquet files. These files can be large and can also create very long file paths on Windows.



The models can alternatively be regenerated by running the relevant notebooks.

\## Notebook Execution Order



Run the notebooks in the following order:




The notebooks depend on outputs generated during earlier tasks and should therefore be executed sequentially.



\## Task 1 - Distributed Data Engineering



`01\_task1\_data\_engineering.ipynb`



This notebook performs:



\- raw data ingestion

\- explicit schema enforcement

\- timestamp cleaning

\- geographic validation

\- missing-data analysis

\- duplicate validation

\- derived temporal features

\- weather-data cleaning

\- supporting dataset preparation

\- Parquet conversion

\- Year and District partitioning



The processed datasets generated by Task 1 are stored under:



```text

data/processed/

```



\## Task 2 - High-Dimensional Exploratory Data Analysis



`02\_task2\_high\_dimensional\_eda.ipynb`



This notebook performs:



\- temporal crime analysis

\- annual crime analysis

\- monthly seasonality analysis

\- average daily crime analysis

\- weekday and hourly analysis

\- community-area analysis

\- three-year rolling averages

\- Spark broadcast joins

\- weather and crime analysis

\- socioeconomic correlation analysis



Generated charts and visualisations are stored in:



```text

outputs/figures/

```



\## Task 3 - Unsupervised Learning



`03\_task3\_unsupervised\_clustering.ipynb`



This notebook performs distributed K-Means clustering using:



\- latitude

\- longitude

\- cyclical time-of-day features



Candidate values of K are evaluated using:



\- within-cluster training cost

\- Silhouette coefficient



The final selected clustering solution uses:



```text

K = 5

```



The trained K-Means model is saved under:



```text

outputs/models/

```



The saved model can either be downloaded from Google Drive or regenerated by running the Task 3 notebook.



\## Task 4 - Distributed Predictive Modelling



`04\_task4\_supervised\_ml.ipynb`



This notebook develops Random Forest classifiers to predict the likelihood of arrest.



The notebook includes:



\- feature preprocessing

\- categorical encoding

\- one-hot encoding

\- median imputation

\- feature-vector assembly

\- baseline Random Forest

\- class-weighted Random Forest

\- confusion matrix

\- accuracy

\- precision

\- recall

\- F1-score

\- ROC-AUC

\- PR-AUC



The generated Spark ML models are stored under:



```text

outputs/models/

```



These model directories are excluded from GitHub because of their size and deeply nested Spark-generated file structure.



\## Running the Project



There are two ways to run the project.



\### Option 1 - Run the Full Pipeline



To reproduce the complete workflow from the raw data:



1\. Download `Crimes\_-\_2001\_to\_Present.zip`.

2\. Extract it into `data/raw/`.

3\. Confirm that the other supporting raw datasets are also inside `data/raw/`.

4\. Run:



```text

01\_task1\_data\_engineering.ipynb

```



5\. Task 1 will generate the processed Parquet datasets under:



```text

data/processed/

```



6\. Continue by running:



```text

02\_task2\_high\_dimensional\_eda.ipynb

03\_task3\_unsupervised\_clustering.ipynb

04\_task4\_supervised\_ml.ipynb

```



\### Option 2 - Use the Pre-Generated Processed Data



To avoid rerunning the complete Task 1 ETL process:



1\. Download `processed.zip` from Google Drive.

2\. Extract it into:



```text

data/processed/

```



3\. Confirm that the processed Parquet folders are available.

4\. Run Tasks 2, 3 and 4.



\### Option 3 - Use the Pre-Generated Spark Models



To use the saved machine-learning models:



1\. Download `models.zip` from Google Drive.

2\. Extract it into:



```text

outputs/models/

```



3\. Ensure the Spark model directories are preserved exactly as they appear in the ZIP file.



The saved models are optional because they can be regenerated by running Tasks 3 and 4.
